## 🚀 How to use

1. Open [`answer-progress.md`](answer-progress.md) and pick an unchecked question.
2. Skim the matching topic in `interview-question-bank/` for a short answer and follow-up ideas.
3. Write the full answer in `answer.md`, following the existing style:
   - Heading = exact question text as `### <question>` (keeps TOC anchors stable)
   - Numbered concept sections, runnable code, a diagram where useful, a **One-Line Interview Answer**, and follow-up questions
4. Add the new answer to the **Table of Contents** at the top of `answer.md` and tick the checkbox in `answer-progress.md`.
